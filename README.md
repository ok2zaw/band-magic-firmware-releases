# Band Magic — Firmware Releases

Public distribution point for [Band Magic](https://github.com/ok2zaw/band-magic)
firmware binaries. The firmware source lives in a private repository; this repo
holds only compiled artifacts and the static web-flasher page, published
automatically by that repo's CI on each tagged release.

## What's here

- **[Releases](../../releases)** — each tagged release attaches
  `bootloader.bin`, `partitions.bin`, and `firmware.bin` for that version.
- **[GitHub Pages site](https://ok2zaw.github.io/band-magic-firmware-releases/)**
  (`docs/index.html`) — a browser-based flasher (via
  [ESP Web Tools](https://esphome.github.io/esp-web-tools/)) for flashing a
  device over USB with no software install. Points at the `latest` release via
  stable `/releases/latest/download/...` URLs, so it never needs updating by
  hand.
- **`docs/manifest.json`** — small JSON manifest (`version`, `url`, `sha256`)
  that a running Band Magic device polls to check for and apply OTA updates
  over the LAN. Regenerated by the source repo's release workflow on every
  tag.
- **`docs/boot_app0.bin`** — fixed OTA-init partition image from the
  Arduino-ESP32 framework, used only by the full USB flash (not part of a
  versioned release; only needs updating if the framework version bumps in
  `platformio.ini`).

## Updating a device

- **Already running Band Magic, on your LAN:** use its own web UI's
  System → Check for OTA update. Updates in place, keeps saved settings.
- **New/unresponsive/USB-connected board:** use the
  [web flasher](https://ok2zaw.github.io/band-magic-firmware-releases/) above.
  Full erase-and-flash; settings are reset to factory defaults.

Nothing in this repo is built here — everything is pushed by the private
source repo's CI.
